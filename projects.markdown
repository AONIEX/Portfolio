<div class="project-card" id="Mesh_Cutting">
  <h2>Mesh Cutting</h2>
  <h3>Game Mechanics Programming Mesh Cutting (3rd Year University Project)</h3>
  <p>The project was made for Game Mechanics Programming (3rd Year Class), where I had to make a unique game mechanic in Unreal Engine 5 using C++ with minimal blueprint use. For this I decided to make a mesh cutting "Weapon" which allowed the player to cut out parts of a mesh, before being able to grab them and then return them to their original position if wanted.</p>

  <img src="{{ 'Assets/MeshCuttingOne.gif' | relative_url }}" alt="Mesh Cutting Gif One">

  <h3>My Focus</h3>
  <p>My core focus in this project was the ability to edit/cut the mesh during run time, splitting into two or more pieces, each with their own physics and collisions. I developed my skills on ray tracing using it to make sure the mesh was cut in the correct positions.</p>

  <h3>Below are the main features used and what I learned</h3>
  <ul>
    <li><strong>Ray Tracing:</strong> Used to figure out the position that the player wanted to cut the mesh, calculate start/end points, check if cuttable, and pick up/move objects.</li>
    <li><strong>Procedural Mesh:</strong> Learned performance needs of editing procedural meshes at run time, deforming/merging meshes, copying component data, and finding the centre of cut meshes.</li>
    <li><strong>Physics and Collisions:</strong> Learned how unpredictable physics can be when slicing meshes and how to minimize chaotic effects.</li>
  </ul>

  <h3>How I would extend this project</h3>
  <p>If I had more time I would advance this project by letting the player cut out more complex shapes, or even custom shapes with the player choosing the shape, as well as refining grabbing mechanics.</p>

  <img src="{{ 'Assets/MeshCuttingTwo.gif' | relative_url }}" alt="Mesh Cutting Gif Two">

  <h3>Extra Information</h3>
  <ul>
    <li>Game Engine: Unreal Engine 5</li>
    <li>Solo Project</li>
    <li>Language: C++</li>
    <li>Ray Tracing, Procedural Mesh Cutting/Deformation/Creation</li>

  <h2>AI Evolution Simulation</h2>
  <h3>AI Evolution Simulation (University Project)</h3>
  <p>This Unity (C#) project simulates how animals evolve over time when faced with basic survival needs such as eating and drinking. Each creature has a set of traits that change across generations, allowing the population to gradually adapt and survive longer using Genetic Algorithms.</p>

  <img src="{{ 'Assets/AI_Mutation.gif' | relative_url }}" alt="AI Evolution Gif">

  <h3>Core Focuses</h3>
  <p>This project explored genetic algorithms, emergent AI behaviour, and long-running simulation design in Unity.</p>

  <h3>How the System Works</h3>
  <ul>
    <li><strong>DNA Crossover:</strong> New animals inherit traits from two parents.</li>
    <li><strong>Mutation:</strong> Traits have a chance to shift slightly each generation.</li>
    <li><strong>Generations & Survival:</strong> Animals live, eat, drink, and die based on hunger/thirst values.</li>
  </ul>

  <h3>Adjustable Settings & Data Storage</h3>
  <p>Modified via Unity UI sliders (population size, food amount, mutation chance). Generation data is logged to a text file for analysis.</p>
